

==**Composition of an npc and a car**==

The relevant clickable elements on the game are mainly the car and (later feature - currently not implemented) the driver.

Each elements are separated from one another in individual object inside another object
-> {driverInformation:{...}, carInformation:{...}, id:123456789}

**Now for individual cases this json may look differ.**
Logging the 'criminal' parameter shows that for example the 'id' is missing.
The reason for this is the **generateWantedListProfiles.js** utils function which generates a criminal without the id. The id gets implemented later in the **useCarSpawnder.jsx** hook.


**persona:** Passing information about npc & car
**npc:** does include information about the npc only 
**car:** does include information about the car only
